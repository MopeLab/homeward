# 《听见来处》参赛提交参考

2026 年 11 月 28 日直接核对了正式问卷，并实测选择 1–4 人时显示的题目。单人 12 项、两人 15 项、三人 18 项、四人 21 项，页面显示的题目均为必填。[正式作品提交问卷](https://bytedance.larkoffice.com/share/base/form/shrcnpAXcVaNrkWnMg4rOSLMPab?from=navigation)

## 问卷字段

| 字段 | 填写参考 |
| --- | --- |
| 报名的场次 | 从下拉列表选实际报名场次。页面同时提供「线上场」和各高校分站。 |
| 队长姓名 | 填报名队长姓名。 |
| 队长学校 | 填队长所在高校的全称。 |
| 队长手机号 | 填报名用手机号。 |
| 队长抖音 UID | 填抖音设置页显示的 `UserID`。 |
| 队伍人数 | 填实际参赛人数，含队长，可选 1–4 人。 |
| 队友 1 / 2 / 3 姓名、手机号、抖音 UID | 按人数展开。两人填队友 1，三人填队友 1、2，四人全部填写。 |
| 作品名称 | **听见来处**。当前编辑器项目使用这个名称，提交时和最终发布的地图名保持一致。 |
| 作品赛道 | **02｜自由幻想成真**。 |
| 作品简介 | 300 字以内，涵盖创意、背景、玩法和体验方式。可直接使用下方文案。 |
| 作品截图 | 上传多张岛内体验截图。 |
| 作品互动演示和讲解视频 | 上传完整互动流程和效果演示的录屏。官方建议约 3 分钟，单个文件不超过 1 GB。见[录制提纲](录制提纲.md)。 |
| 开发版本预览二维码 | 从「抖音虚拟创作平台 → 管理 → 版本管理 → 开发版本」取得该地图的二维码。 |

抖音 UID 查找方法见表单。抖音 App 内打开「我 → 右上角菜单 → 设置」，滑到底部。安卓连续点五次「抖音 version」，iOS 在底部灰色文字处用三指点四次，读取显示的 `UserID`。

## 作品简介

如果只能寄三种声音回家，你会选哪三种？

晚课散了，家里问你那边下不下雨。雨敲着校园的铁皮棚，跨过一根立柱，又落进旧屋檐下的搪瓷碗。石阶尽头泊着一艘末班船。你在船头听声选岸，去早市听卷帘门把清晨拉开，或去放学路等一声车铃、等钥匙在锁里轻轻一转。

七处声源各有两拍。挑三声放进明信片，试听、换格、重排，回到宿舍窗边盖章。三幅速写随着声音一格格显影。也可以把设备递给身边的人，轮流选声，在同一封信上留下两枚章。

楼下有人喊你吃饭。这一声，也寄回家吗？

Sound effects from ZapSplat

## 提交时核对

- 场次、队长和队友信息按报名记录填写。
- 视频、岛内截图和开发版本二维码对应同一地图。提审进度在编辑器内另行记录。研发与验收基线见 [05 录制版本交接](../05-playtest.md)。
- 卷帘门音效署名可保留在简介最后一行，并放在演示片尾。[现用音轨与署名](../../Audio/README.md)
