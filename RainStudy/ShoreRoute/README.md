## 泊位与返程

校园跳板从 n9 接出。中央船头听区在 (0,0,15)，左预听卷门，右预听车铃。两处靠岸点为 (-11,0,20.5) 和 (11,0,20.5)，登岸朝 +Z，回船朝 −Z。选岸接亮对应岸灯，船尾暖灯指向宿舍，返回地点 (0,0,9.7) 靠近回信桌与室友听区。回信桌 (-1.2,0,8) 留给原有个人卡和合写操作。

两岸美术采用[构图参考](./shore-reference.png)。晨市以低横棚、半开铁门和侧逆光中的白汽作识别；暮路采用缓坡、横跨天空的电线以及窄竖暖门缝。参考图用于选材、打光和构图。背景远景可简化，四件可采物件和两个泊位优先保留近景可读性。

04 可按以上位置剪声、画图，使用原 RainHost 的 S03A 至 S06B。岸上底声使用 MarketBed 与 DuskBed。新音频在本轮先用线程 03 的原创合成占位，供实装与回放验收用，正式版仍由 04 接手。
